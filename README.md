# 🎥 3D OBJ Viewer

A **web-based 3D model viewer** that allows users to **upload and view `.obj` models with `.mtl` materials** inside a browser. The application uses **Three.js** for rendering 3D models and **Bootstrap** for styling.

---

## 🚀 Features
✅ **Interactive 3D Model Viewer** – Load and view `.obj` models with `.mtl` materials.  
✅ **User-Friendly UI** – Simple and responsive design using Bootstrap.  
✅ **Model Controls** – Rotate, zoom, and move the 3D model with **OrbitControls**.  
✅ **Model Animation** – Start/stop automatic model rotation.  
✅ **Upload Custom Models** – Load `.zip` files containing `.obj` and `.mtl` files.  
✅ **GUI Customization** – Modify model position, scale, and wireframe mode using `dat.GUI`.  

---

## 🛠 Tech Stack
- **Frontend**: HTML, CSS (Bootstrap)  
- **3D Graphics**: Three.js (OBJLoader, MTLLoader, OrbitControls)  
- **User Interface**: dat.GUI (for adjusting model settings)  
- **File Handling**: JSZip (for loading `.zip` files)
